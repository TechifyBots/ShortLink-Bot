## 🌸 Overview

**ShortLink Bot** is a powerful and easy-to-use **Telegram bot** that lets you **shorten URLs** quickly using multiple supported **shortener services**.

> *💡 Turn long URLs into short, shareable links in seconds.*

#### 🤔 Why Choose This Project?

- ⚡ **Fast & Reliable** — Shorten URLs quickly with a smooth Telegram workflow.
- 🔗 **Multiple Shorteners** — Support for custom shorteners and TinyURL.
- 🛠️ **Powerful Controls** — Includes Force Subscribe, broadcasting, logging, and maintenance mode.
- 🚀 **Easy to Deploy** — Simple configuration makes self-hosting straightforward.

#### 🔄 How It Works

1. 🔗 **Send Your URL** — Send any supported URL to the bot.
2. ⚡ **Process the Link** — The bot sends your URL to the configured shortener.
3. ✨ **Get Your Short Link** — Receive the shortened URL instantly.
4. 📤 **Share Anywhere** — Copy and share your new short link.

---

## ✨ Features

- 🔗 **Multiple Shorteners** — Support for custom shorteners and TinyURL.
- ⚡ **Instant URL Shortening** — Quickly generate shortened links directly from Telegram.
- 🔐 **Force Subscribe** — Require users to join configured channels before using the bot.
- 📢 **Broadcast System** — Send announcements and updates to all bot users.
- 📊 **Bot Statistics** — View useful user and usage statistics.
- 🛡️ **User Management** — Ban, unban, and manage bot users easily.
- 📝 **Logging System** — Track important bot activity through the configured log channel.
- 🔧 **Maintenance Mode** — Temporarily disable bot services when needed.
- ⚙️ **Flexible Configuration** — Easily configure the bot through environment variables.
- 🚀 **Easy Deployment** — Simple setup for self-hosting and deployment.

## 📝 Configuration


| Variable | Description |
|:---------|:------------|
| `API_ID` | Telegram API ID |
| `API_HASH` | Telegram API Hash |
| `BOT_TOKEN` | Telegram Bot Token |
| `DB_URI` | MongoDB URI |
| `ADMIN` | Telegram User ID |
| `PICS` | Start Images |
| `IS_FSUB` | Enable / Disable Force Subscribe |
| `FSUB_EXPIRE` | Force Subscribe Expire Time |
| `AUTH_CHANNELS` | Force Subscribe Channels |
| `AUTH_REQ_CHANNELS` | Request FSUB Channels |
| `LOG_CHANNEL` | Log Channel |
| `VERSION` | Bot Version |
| `PING_URL` | Service URL for Keep-alive |

## 🤖 Commands

```
start - Check Bot Alive.
stats - Check bot stats.
help - Bot usage guide.
ban - to ban a user.
unban - to unban a user.
info - To check your info.
tiny - To short url using tiny.
banned - to check banned users.
shortlink - To connect your custom shortener
maintenance - Toggle maintenance mode
broadcast - Broadcast messages to all bot users.
```
